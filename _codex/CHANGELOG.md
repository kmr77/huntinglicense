# CHANGELOG

管理環境とサイトに対する完了済みの変更を簡潔に記録する。詳細と確認結果は `logs/` を参照する。

## 2026-10-04

### Changed

- 模擬試験で発見した問題データ不整合を修正（No.138、141、143、208、211、214、217）。No.221は問題画像を差し替え。DB修正はローカル・本番へ反映済みで、会社環境DBは別途同内容を反映する。
- 本番形式模擬試験の免許選択説明文とボタン群の間に16pxの余白を追加。
- 模擬試験の採点結果で、再挑戦ボタンを試験種類ごとの文言にし、「模擬試験一覧に戻る」リンクを追加。狭い画面ではボタンを縦に並べる。

## 2026-10-01

### Added

- 模擬試験の共通テンプレートに既存の`parts-ads`を各ページ2枠配置。問題フォーム内には広告を置かない。

### Removed

- 通常問題の自己判定ボタン、結果メッセージ、JSでのUI生成・正誤保存処理、専用CSSとdata属性を削除。模擬試験の採点記録と復習ページの回答記録は維持。

### Changed

- 学習記録・復習ページを模擬試験と同じ幅、緑の見出し、白いカード、統計グリッド、丸型ボタンに統一し、390px表示に対応。
- 両固定ページがスラッグによるテンプレート選択でも専用CSS・JSを読み込むよう修正。記録・判定・タイマーの処理は変更していない。
- 学習記録の受験履歴と要復習0件の表示を明確化。

## 2026-09-30

### Added

- ブラウザ内の学習記録、弱点判定、目標試験日、模擬試験履歴・所要時間の処理を追加。
- 学習記録と1問ずつの復習用テンプレート、専用CSSを追加。固定ページはDBに未作成。
- 通常問題の自己判定と模擬試験の実経過タイマー・結果保存、TOPと模擬試験からの学習記録導線を追加。

### Changed

- 新規ページにランダム切替ボタンがない場合、`common.js` がイベント登録を省略するようにした。
